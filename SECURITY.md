# Security policy

## Supported versions

Until the first release, only the latest commit on `main` is supported.

## Reporting

Report security issues privately through GitHub's private vulnerability reporting feature. Do not open a public issue containing secrets, third-party application internals, production endpoints, or instructions for bypassing access controls.

## Research boundaries

This project does not accept credential extraction, authentication bypass, certificate-pinning bypass, payment-token handling, device-attestation bypass, or interaction with third-party production services.
