# BrewGo v0.1.0

The first verified BrewGo release delivers an original, offline-first coffee ordering demonstration for Android-targeted Expo and static web.

## Highlights

- synthetic store selection with pickup and delivery contexts;
- original searchable catalog and product customization;
- canonical cart-line identity, quantity editing, and integer-fen pricing;
- deterministic demo coupons with explicit rejection reasons;
- validated mock checkout with no payment processing;
- SQLite cart recovery and immutable local order history;
- deterministic pickup and delivery status progression;
- corrupt-data quarantine and explicit recovery feedback;
- accessible controls and loading, empty, error, unavailable, validation, and success states.

## Verification

- strict TypeScript, ESLint, and Prettier checks;
- 31 unit and integration tests;
- repository prohibited-content scan;
- Android Expo export;
- static web Expo export with SQLite WASM;
- clean-checkout GitHub Actions verification.

## Release boundary

This release contains source code and sanitized documentation only. It contains no application packages, generated platform bundles, extracted resources, decompiled output, credentials, production endpoints, proprietary assets, or raw research evidence.

All stores, products, prices, coupons, addresses, order identifiers, and fulfillment states are synthetic or deterministic local demo data. No external service or payment system is contacted.
