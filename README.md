# BrewGo

BrewGo is an independently designed, offline-first coffee ordering demo built with Expo and React Native.

## Project status

The repository is being delivered through six verified milestones:

1. REA environment readiness
2. Authorized APK identification
3. Evidence-backed behavior mapping
4. Clean-room product specification
5. Core ordering demo
6. Verification and v0.1.0 release

## Clean-room boundary

Only original BrewGo source, synthetic fixtures, and sanitized behavioral specifications belong in this repository. Third-party application packages, extracted resources, decompiled output, production endpoints, credentials, signing material, and raw reverse-engineering evidence must remain outside Git.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the contribution and provenance rules.
